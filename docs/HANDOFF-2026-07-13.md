## Gotchas learned this session

- `notionalNow` frontend crash = stale cached `/api/trades/stats` (service worker is network-first but
  the browser HTTP-cached the old response). Fixed defensively; watch for this pattern on any new API field.
- Auto-select re-promotes manually-pruned cells unless they're in `AUTOSELECT_DENYLIST` (env, now wired).
- The net-cost backfill is **not idempotent** — never re-run it (it subtracts costs from already-net pnl).
