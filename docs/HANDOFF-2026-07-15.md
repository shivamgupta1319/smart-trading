## Gotchas learned this session

- **Login 502 after any deploy that recreates `api`:** frontend nginx cached the old api IP (no `resolver`).
  Fixed permanently (variable proxy_pass + docker resolver). If it recurs on old config: `docker exec
  smart-trading-v2-frontend nginx -s reload`.
- **The risk cap is ADDITIVE, not a model swap** — ₹10k/compounding/leverage all intact. Owner briefly
  thought the model was replaced; it wasn't.
- **Backfill is idempotent-ISH but the deletion is not** — never re-run the deletion; restore from the
  pre-deletion pg_dump if you need the full history.
- **Monitored tab vs Actual Portfolio "mismatch" was a scope difference, not a bug** — active cells vs all
  history. Now moot after the deletion (all traded cells are active), but the reconciliation cards remain.
- **Current book is survivorship-biased** — don't quote +₹4,309 / PF 3.28 as the true forward edge.
